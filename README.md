## Опис проєкту

Проєкт демонструє побудову спеціалізованого AI-агента (`build-engineer`) із набором повторно використовуваних навичок (`skills`), іменованих команд (`prompts`) та оркестратора (`init`) для автоматизованого створення, складання, модульного тестування й кросплатформної перевірки Java-застосунку *Hello World* у середовищі GitHub Actions (Ubuntu, Windows, macOS).

## Як запустити AI-агента

Після розгортання структури агента в гілці `develop` повний цикл генерації та перевірки виконується через оркестратор у VS Code Copilot Chat:

1. Відкрити репозиторій у Visual Studio Code із активованим розширенням **GitHub Copilot**.
2. Обрати агента **`build-engineer`** (або викликати команду-оркестратор):
   - `/init` — послідовний запуск усіх етапів (`git-init` → `create-project` → `create-build` → `create-actions` → `check`) із зупинкою при першій помилці.
3. Окремі команди для точкового запуску:
   - `/git-init` — перевірка стану Git і налаштування `.gitignore`;
   - `/create-project` — створення базової структури Maven та класу застосунку;
   - `/create-build` — конфігурація `pom.xml` і модульних тестів JUnit 5;
   - `/create-actions` — генерація скриптів `scripts/ci.sh`, `scripts/ci.bat` та `.github/workflows/ci.yml`;
   - `/check` — перевірка структури, збірки, тестів і YAML без внесення змін у код.
